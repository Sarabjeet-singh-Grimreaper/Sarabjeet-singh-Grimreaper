## Featured Project

### 🧠 AI Fake News Detection System

An end-to-end fake news detection platform combining **Machine Learning** with **Explainable AI** — built for interpretability, not just accuracy.

```
Input News Article
       │
       ▼
┌─────────────────────────────┐
│  30+ Stylometric Features   │  ← Deep linguistic & stylistic analysis
│  Chi-Square Feature Filter  │  ← Statistical dimensionality reduction
│  ML Classification Model    │  ← Prediction with confidence scoring
│  XAI Explainability Layer   │  ← Human-readable decision breakdown
│  Domain Trust Analysis      │  ← Automated source credibility check
└─────────────────────────────┘
       │
       ▼
  Flask Dashboard → Real-time verdict + probability output
```

**Stack:** Python · Scikit-learn · Flask · Pandas · NumPy
