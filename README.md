# 🚀 Featured Project

## 📰 AI Fake News Detection System
> Machine Learning • NLP • Explainable AI • Flask • Data Analysis

A machine-learning system that classifies news content and surfaces interpretable reasoning behind its predictions.

**Key features:**
* 🧠 ML classification of likely fake vs. genuine news
* 📊 30+ stylometric (linguistic/stylistic) features extracted from text
* 🎯 Chi-Square statistical filtering for feature selection
* 🔎 Explainable AI output for model predictions
* 🌐 Domain trust analysis of news sources
* 📈 Confidence scoring on predictions
* ⚡ Interactive Flask dashboard for submitting content and viewing results
* 🔄 Automated pipeline: preprocessing → feature extraction → prediction → evaluation

**Stack:** `Python` `Pandas` `NumPy` `Scikit-Learn` `NLP` `Flask`
